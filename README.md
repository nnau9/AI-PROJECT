# NNATO

Информационный и консультационный сервис для студентов из Казахстана, которые рассматривают программу **Summer Work Travel USA** (BridgeUSA, виза J‑1): путь участника, сравнение агентств по проверяемым параметрам, расходы и риски, годовые тарифы сопровождения NNATO.

> NNATO не является спонсором J‑1, визовым посредником или агентством по трудоустройству и не гарантирует участие, работу, доход или визу. Решение о визе принимает консульский сотрудник США. Шаги, требования и расходы на сайте — общая информация, а не индивидуальная юридическая или визовая инструкция.

## Запуск

Требуется Node.js 18+ (проверено на 22.11) и npm.

### Web

```bash
cd web
npm install
npm run dev               # http://localhost:5173
npm run build             # production-сборка в web/dist (статический хостинг)
npm run build:standalone  # один HTML-файл → web/dist-standalone/index.html и копия в корневой index.html
```

`build:standalone` перезаписывает корневой `index.html` только если он пустой или ранее создан этой сборкой (метка `swt-standalone`). Маршрутизация — `HashRouter` (`#/agencies`), поэтому сайт работает на любом статическом хостинге и при открытии файла напрямую.

### Mobile

```bash
cd mobile
npm install
npx expo install --check   # выровнять версии под Expo SDK
npm start                  # QR-код для Expo Go; a — Android, i — iOS
```

Metro настроен (`metro.config.js`) так, чтобы видеть `../shared`. Мобильный UI — собственные нативные компоненты с теми же токенами и подписью бренда (`mobile/src/theme.js`); общие только данные и бизнес-функции. Мобильное приложение проверено на синтаксис и разрешение импортов; на устройстве не запускалось.

### Тесты

```bash
cd shared && npm test
```

Проверяют: все `sourceId` существуют; в данных нет сведений о казахстанской лицензии и юрлице агентств; у агентств есть обязательные поля и сведения о спонсоре J‑1; у каждой цены агентства есть валюта, сезон, включено/не включено, источник и дата; цены тарифов NNATO точные (5 990 / 7 990 / 15 999 ₸ в год); у $17/час есть оговорка; фильтры, валидация, прогресс чек-листа.

## Цены тарифов NNATO

Редактируются в **`shared/data/plans.json`** → `plans[].price` (число) и `plans[].currency` (`"KZT"`). Отображение «5 990 ₸ / год» строит `formatPlanPrice()` из `shared/src/services/plans.js` — в JSX цены не хранятся. Дата актуальности прайса — `meta.priceSetAt`.

| Тариф | Цена |
|---|---|
| Lite | 5 990 ₸ / год |
| Classic | 7 990 ₸ / год |
| All-in | 15 999 ₸ / год |

Состав тарифов — `features[]` и `plans[].features`. Сноска к $17/час — `footnotes["offer-floor"]`.

Цены NNATO не смешиваются с расходами на программу: расходы на SEVIS, визу и поездку — в `important-notes.json → costItems`, цены агентств — в `agencies.json → publishedPrices` (с `currency`, `season`, `included`, `notIncluded`, `sourceId`, `asOf`).

## Окружение и подключение backend

| Переменная | Где | Назначение |
|---|---|---|
| `VITE_API_BASE_URL` / `EXPO_PUBLIC_API_BASE_URL` | `web/.env.local` / `mobile/.env` | API контента. Пусто → локальные JSON |
| `VITE_LEADS_ENDPOINT` / `EXPO_PUBLIC_LEADS_ENDPOINT` | то же | POST заявок. Пусто → демонстрационная заглушка |

**API контента**: `GET {base}/content/{name}`, где `name` ∈ `program | steps | agencies | sponsors | plans | importantNotes | sources`; ответ — та же структура, что у JSON-файла.
**Заявки**: `POST {endpoint}` с JSON `{ name, contact, city, planId, message, consent }`. Пока endpoint пуст, данные никуда не отправляются и нигде не сохраняются; форма честно сообщает о демонстрационном режиме. Оплаты на сайте нет.

Перед запуском продаж нужны: текст согласия на обработку персональных данных и договор-оферта (начало периода, оплата, возврат).

## Как редактировать контент

Каждый изменяемый факт ссылается на источник (`sourceIds`/`sourceId`) и имеет дату проверки. После правок — `npm test` в `shared/`.

### Источник (`sources.json`)
```json
{ "id": "my-source", "title": "…", "publisher": "…", "url": "https://…", "kind": "official|agency|design",
  "status": "ok|partial|blocked|not_reviewed", "checkedAt": "2026-11-11", "note": "что именно подтверждает" }
```

### Агентство (`agencies.json → agencies[]`)
- Только то, что найдено в источнике; самоописание — в `claims[]` (в интерфейсе — «заявление организации»).
- **Не добавляйте** сведения о казахстанской лицензии и юрлице агентства — тест это запрещает.
- `contacts` — только реально найденные ссылки; `contacts.checkedAt` — дата сверки.
- `usSponsor` — американский спонсор J‑1: `claimedNames`, `sponsorIds` (id из `sponsors.json`), `relationStatus: "agency_claim"` (пока нет подтверждения от спонсора), `officialRecordUrl` — запись BridgeUSA.
- `verificationStatus`: `sponsor_listed` — названный спонсор есть в списке BridgeUSA; `claims_only` — только заявления; `needs_check`; `verified` — только при независимом подтверждении.
- `publishedPrices[]` — `amount`, `currency`, `season` (или `null`, если не указан), `included[]`, `notIncluded[]`, `sourceId`, `asOf`; устаревшие — `"stale": true`, закрытый набор — `"closed": true`.
- Порядок карточек — алфавитный; это не рейтинг.

### Шаги (`steps.json`)
`phase`, `dependsOn` (`sponsor | agency | season | embassy`), `checklist[]`, `sourceIds`.

## Дизайн

Визуальный ориентир — ясность, крупные короткие заголовки, свободное пространство и плитки разделов (по мотивам подхода apple.com), но дизайн собственный: без элементов, текстов, изображений и логотипов Apple.

- **Подпись NNATO** — «солнце над горизонтом»: знак в шапке (`web/src/components/Brand.jsx`) и пунктирный маршрут Казахстан → США. Маршрут теперь проложен по глобусу на первом экране главной; исходная SVG-схема осталась в `Art.jsx`.
- **Глобус на главной** — `web/src/components/Globe.jsx`: точечная сфера на Canvas 2D без сторонних библиотек. Плоская заливка диска, суша — квадратные точки в 4 тонах (свет квантуется, без градиентов), сетка 30° линиями 1px, кобальтовый пунктир маршрута с этапами 01–04. Цвета берутся из токенов, поэтому работает в светлой и тёмной теме. Медленно вращается, наклоняется за курсором, крутится перетаскиванием (с инерцией) и стрелками клавиатуры (Home — исходный вид); есть кнопка остановки вращения. Цикл анимации останавливается вне экрана и в скрытой вкладке; при `prefers-reduced-motion` вращения и наклона нет. На телефонах — реже точки, 30 кадров/с, DPR ≤ 1.5. Подача по мотивам fojcikdominik.com (сцена во весь экран, подписи по углам, моноширинные метаданные, нумерованный указатель разделов) — без его шрифтов, цветов и кода.
- **Маска суши** — `web/src/assets/land-mask.js` (11 КБ), генерируется `node web/scripts/build-land-mask.mjs <land-110m.json>` из Natural Earth 1:110m (общественное достояние, пакет world-atlas@2.0.2).
- **Фотографии** — 7 снимков CC0 (Wikimedia Commons) в `web/src/assets/photos/` (WebP, ~0,9 МБ), подключаются через `Photo.jsx` и манифест `assets/photos/index.js`. Каждое фото привязано к смыслу секции: дом (Алматы), сезонная работа, цель поездки (Нью-Йорк). Источники и авторы — в [ASSETS-CREDITS.md](ASSETS-CREDITS.md).
- **Композиция** — чередование светлых и тёмных секций, фото во всю ширину, списки с линиями вместо однотипных карточек; декоративных градиентов нет (затемнение под текстом на фото — только для контраста).
- **Шрифт** — системный стек (`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", …`) с кириллицей. SF Pro не встраивается: его лицензия разрешает шрифт только для макетов интерфейсов под платформы Apple.
- **Доступность** — контраст текста не ниже 4.5:1 (для текста в цвет подписи используется `--sig-ink`), видимый фокус, области нажатия ≥ 44px, нижняя навигация на телефоне, `prefers-reduced-motion` отключает анимации появления и маршрута, тёмная тема по `prefers-color-scheme`.

## Что требует дополнительной проверки (на 11.11.2026)

- **travel.state.gov и сайт посольства США в Казахстане** при повторной проверке снова вернули HTTP 403: размер визового сбора, порядок DS-160 и запись на собеседование не подтверждены (агентства называют $180 и $185).
- **SEVIS I-901**: ICE — $35 для «special J-visa categories» и $220 полная ставка; что SWT относится к льготной категории, ни одна официальная страница прямо не подтвердила.
- **Окно программы для Казахстана** в 2026 Program Date Chart (PDF) не прочитано; страница программы BridgeUSA всё ещё ссылается на календарь 2024 года. Правило DHS от 17.07.2026 о сроках допуска J‑1 не разбиралось.
- **Visa Waiver Program** — статус Казахстана по официальному списку не подтверждён.
- **Список спонсоров BridgeUSA** озаглавлен «2024» и отражает участников прошлого года.
- **Агентства**: контакты сверены с их сайтами 11.11.2026; связь агентств со спонсорами (ABC Universe → CIEE и Alliance Abroad; IEC → InterExchange) — только заявления агентств; KCET, American Trip и Work and Travel USA KZ спонсора не называют; цены Work and Travel USA KZ — за прошлый сезон; у KCET не указаны сезон и состав цены; American Trip не указывает город и адрес.
- **Медицинская страховка** — требования 22 CFR 62 в контент не переносились.
